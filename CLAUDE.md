# flurry map

Rust Wayland shell (no GTK, no async runtime), consumed by borealis. Public repo: no private info, no hardcoded user paths (use `lib/xdg.rs`).

- `flake.nix`: `packages.default` (`package.nix`), `packages.sideview` (`sideview/package.nix`, Servo, built from the separately pinned `nixpkgs-servo` input), `homeManagerModules.default` (`hm-module.nix`, `programs.flurry.{enable,settings,package}`, systemd user service, `Restart=always`).
- Settings are Nix-only: `package.nix` holds the only defaults and writes `settings.rs` at build (validated at eval); unset hm options are null and take them. The checked-in `settings.rs` is the dev build's copy of those defaults. Never runtime config files. `programs.flurry.settings`: sideview (the built-in "assistant" page is in `widgets/sideview.rs`), bluetoothNames, soundNames, playlists ({name,color}), mpdCrossfade, syncCommand, fileManager, imageViewer, focusBlocked, wallpaperDir (relative = under $HOME), passSyncCommand (run only if argv[0] is on PATH), nightLight ({dark,light} kelvin or false), notificationFilters (argvs are lists), fonts (fallback font packages).
- System side (not in the module): `security.pam.services.flurry-auth = {}` is required for unlocking (optional `flurry-fprint` for fingerprint); a missing `/etc/pam.d/flurry-auth` is reported at start (notification + stderr). Combined output (Shift+Enter in the output selector) needs an external PipeWire null sink named `combined-bt-sink` (e.g. `services.pipewire.extraConfig`); without it a single sink is picked. Runtime tools not wrapped into PATH: xdg-open, gpu-screen-recorder, pass, systemd-run, claude (for the assistant), the wl-gammarelay service (night light), and whatever the settings' argvs name.
- `app.rs`: shell entry (`flurry-shell`); `client.rs` is `flurry <cmd> [arg]`, the libc-only request client for sway keybinds (no args execs the shell); one datagram to `$XDG_RUNTIME_DIR/flurry.sock` (path from `lib/xdg.rs`, shared by both).
- `ui/`: the toolkit: `runtime.rs` (single poll loop, timers, idle, tiny executor), `wayland/` (`mod.rs` outputs, seat and the queue; `surface.rs` layer and lock surfaces; `lock.rs` ext-session-lock; `clipboard.rs` wlr-data-control; `shm.rs` buffers), `node.rs` (GTK-like box model + painting), `text.rs` (HarfBuzz; no fontconfig at runtime: `package.nix` runs `fc-match` at build over Sora, decompressed from sideview's vendored woff2, plus `settings.fonts` into `settings.rs` `FONTS`; the dev shell passes the same table as `FLURRY_FONTS`), `image.rs`, `icons.rs` (baked by `build.rs`), `entry.rs`, `window.rs`.
- `lib/`: services (dbus, logind, iwd, bluetooth, battery, brightness, audio=pipewire, notifd, apps, sway, mediaPlayer=mpd, pam, wallpaper, clipboard, streamingMode), plumbing (process: pidfd children; xdg; state: `global_state!`; time, random, json, notifySend), and shared widgets/behaviors (searchDialog, inputControl, backgroundSection, deviceMenu, menuWindow, menuState, outTransition, wrapFocus, scrollStep); `style.rs` holds the resolved CSS values.
- `widgets/`: one file or directory per window.
- `sideview/`: separate crate `flurry-sideview` (Servo), spawned by `widgets/sideview.rs` on the first show, commands over stdin, "mapped"/"closed"/"open <url>" back on stdout (flurry opens links: the helper has no sway or session bus). Its package runs it in a bubblewrap sandbox (store, /etc, GPU, Wayland socket, network; writable: its data dir, ~/.claude, ~/.claude.json). `flurry:claude` pages are `sideview/claude/` (vendored marked + KaTeX + Sora variable font) talking to `claude -p` stream-json via `src/claude.rs`, std+libc only so the main crate tests it (`cargo test --test sideview-claude`; CI can't build Servo).
- Dev: `nix-shell` (or `nix develop`; same nixpkgs, from `flake.lock`), `cargo test`, `cargo clippy`, `cargo build --release`.
- Visual check: `tests/capture/run.sh <flurry-client> <out-dir>` (the `flurry` binary; it starts the sibling `flurry-shell`) captures every window but the sideview in an isolated headless sway (never the live session); compare with `tests/capture/sbs.sh`.
- Build: `nix build .#default`.
